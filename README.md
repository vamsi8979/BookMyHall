# BookMyHall

A web application for searching and booking function halls online.

## Live Demo

https://bookmyhall-8x4c.onrender.com/

## Tech Stack

* Node.js
* Express.js
* MongoDB
* Mongoose
* EJS
* Passport.js
* Nodemailer

## Features

* User registration and authentication
* Function hall search
* Hall details and availability
* Function hall booking
* Owner portal for managing hall details
* Password reset through email

## Project

This was my B.Tech final-year project, developed in 2018 as a function hall reservation system.

> This repository represents the original project and its technology stack from that period.

## Running Locally

```bash
npm install
npm start
```
